# Neovim Plugin Reference

- Alpha: custom Revan header, startup stats, `Ready to code!`
- Neo-tree: toggle/focus keymaps, Git symbols, auto-open, transparency/background fixes
- fzf-lua: file/text/buffer/help/recent-file pickers
- better-escape: `jk` and `jj`
- Conform: Python `ruff_format`, skip format-on-save above 1 MiB
- nvim-lint: Python `ruff`
- lualine: disabled on Alpha
- which-key: no additional custom groups currently
- themes installed include Tokyo Night, Nord, Nightfox, Catppuccin, Nordern, Monokai Pro, Eldritch, Gruvbox Baby, and Poimandres
